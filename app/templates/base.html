Welcome to the Lottery Predictor

This app uses statistical analysis and machine learning to predict CA Lottery Daily 3 and Daily 4 numbers. You can analyze historical patterns, generate predictions, track your own picks, and backtest strategies.

Feature Cheatsheet

Draw History
Latest Daily 3 and Daily 4 results with digit balls, draw numbers, and midday/evening badges.
Frequency Chart
Bar chart of digit frequency (0-9) over the last 100 Daily 3 draws. Quick visual for hot numbers.
Refresh Data
Pulls latest draws from the CA Lottery API. Click anytime to stay current.
Digit Frequency
Per-position frequency of each digit. Green = above expected (10%), red = below. Adjust window size (50/100/200/All).
Hot & Cold
Digits significantly above (hot) or below (cold) expected frequency, based on standard deviation.
Gap Analysis
Draws since each digit last appeared per position. "Overdue" = current gap exceeds average.
Pair Heatmap
10x10 grid of adjacent digit pair frequencies. Darker = more frequent. Hover for count.
Sum Distribution
Histogram of digit sums. Yellow line = mean. Useful for filtering unlikely combinations.
Trends
Rolling average digit value per position over time as a line chart.
Ensemble Prediction
Primary prediction combining all strategies via calibrated weights. Shows digits, confidence %, play type, and expected value.
Strategy Breakdown
Expand to see each algorithm's individual prediction.
Play Types
Straight = exact order. Box = any order. Straight/Box = split bet. Combo = all permutations.
Confidence
Based on probability distribution entropy. Low entropy = higher confidence. Range: 3-8%.
Expected Value
Estimated return per $1 wagered. Positive = the model thinks this is a +EV bet.
Record Picks
Enter digits, date, draw time, play type, and wager. Scored automatically against real results.
Score All
Batch-score unscored entries after new draws are fetched.
Accuracy Stats
Hit rates, net profit, ROI, streaks. Broken down by game and play type. 18-month retention.
Filters
Filter by All / Daily 3 / Daily 4 to see game-specific accuracy.
Walk-Forward
For each past draw, the model uses only prior data. No future data leakage.
Training Window
Past draws used to train before each prediction. Larger = more data, slower adaptation. Default: 200.
Metrics
Hit rates, Sharpe ratio, calibration error, ROI, and comparison to random baseline.
Compare
Select multiple runs to compare strategies side-by-side with charts and significance tests.
Ensemble Weights
How much the system trusts each strategy. Auto-adjusts based on accuracy. Floor: 0.125%, cap: 50%.
Degradation Alerts
Warns when 7-day performance drops below 90-day baseline. WARNING at z<-2, CRITICAL at z<-3.
Calibration Curve
Predicted confidence vs actual hit rate. Well-calibrated = follows the diagonal.
Recalibrate
Manually trigger weight recalculation. Normally runs weekly on Sunday.
Frequency
Most common digit per position over last N draws.
Cold/Due
Digits with longest gap since last appearance.
Positional Trend
Exponentially weighted moving average — recent draws count more.
Pair Analysis
Chains most frequent adjacent digit pairs across positions.
Moving Average
Rolling mean digit value per position, rounded.
Random Forest
ML model, 130+ features, 10-class classifiers per position. Needs 200+ draws.
XGBoost
Gradient-boosted trees, same features. Often better at nonlinear patterns.
LSTM
Deep learning on sequences of 50 draws. Needs 500+ draws. Retrains monthly.
Theme Dots
Sidebar (desktop) or header (mobile) — click dots to switch: Aurum (gold), Fortuna (amber), Oraculo (terracotta).
Auto Rotate
Sidebar "Auto" button cycles themes every 30 seconds. Persists across sessions.
Help ?
Floating button opens this cheatsheet. Launch page walkthroughs from each tab.
Mobile
Bottom navigation for quick access. Hamburger menu opens full sidebar with all options.
